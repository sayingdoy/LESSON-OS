## 编号空间（跨项目共享 · 只增不回收）

⚠️ **本仓 ADR 编号不是纯本地序号，而是三个学习项目共享的编号空间。**
证据：`ADR-0006` / `ADR-0008` 的实际日期是 **2026-10-06 / 10-07**（bb-prep 侧先定），
到 **2026-10-11 才补档进本仓** —— 编号沿用当时已引用的号，**不重排**。

**空洞号 `0005` / `0007`**：截至 2026-10-13，全仓（含 bb-prep）
**零引用、零实体**。它们是编号空间里被**跳过**的号，不是「缺失的文件」。

> **处理原则：保留、不回收。**
> 既然 6 / 8 号已按「跨项目编号」被正式引用，把 5 / 7 号回收给新决策，
> 会造成**同一编号在不同语境下含义不同**（同名异义）。宁可留洞。

**新增 ADR 时**：取**当前最大号 + 1**（现为 `0009`），并在本表的台账里补一行。

## 引用铁律

🔴 **凡被引用的编号，必须有实体文件。**
（历史缺陷：曾出现 `ADR-0006` / `ADR-0008` 被引用却无文件；`ADR-0001` 只有内联示例。
2026-10-11 R1 裁决「C1 余」已补建实体。）

自查命令（全仓引用 vs 实体对照）：

```bash
git -c core.quotepath=false grep -oh "ADR-[0-9]\{4\}" -- . | sort -u   # 被引用的
ls ADR/ | grep -o "ADR-[0-9]\{4\}" | sort -u                            # 有实体的
```
