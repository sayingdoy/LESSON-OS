# ADR 模板

> 架构决策记录（Architecture Decision Record）。每次对内核边界 / API / 版本策略的
> 不可逆决策都记一条。轻量、追加式、不删改旧记录。

**文件名**：`ADR-XXXX-<简短主题>.md`（XXXX 从 0001 递增）

---

## ADR-XXXX · <主题>

- **状态**：提议 / 已采纳 / 已弃用
- **日期**：YYYY-MM-DD
- **决策人**：<名字 / agent>
- **背景**：为什么现在要做这个决定？（触发条件、约束、痛点）
- **决策**：我们决定 ______。
- **理由**：
  - 依据 1（可引用 Karpathy 准则编号 / 实测数据 / 项目铁律）
  - 依据 2
- **影响**：
  - 正向：______
  - 负向 / 代价：______
  - 受影响文件：`<path>`
- **备选方案**（被否决的）：
  - 方案 A：______（否决理由）
  - 方案 B：______（否决理由）
- **后续**：是否有 P2 / 待验证项？

---
