# ADR-0006 · 密钥与判分隔离（交付物不含答案）

- **状态**：已采纳
- **日期**：2026-10-06（bb-prep 起）；2026-10-11（LESSON-OS 补档）
- **决策人**：Jason（Owner）／bb-prep 引擎

## 背景

三个学习项目（bb-prep / vocab-app / AI-Kongzi）都把"题目 + 答案"放在同一份
Markdown 条目里。若直接把条目复制成卷面，答案随卷面泄出 —— 练习即失效。

需要一条跨项目通用的隔离约束，让**交付物（卷面 / 练习文件）天然不含答案**。

## 决策

**密钥与卷面物理分离，密钥不进交付物。**

- 每份卷对应一个 key 文件，写"题号 = 条目 id（`@` 后为该卷面答案字母）"。
- key 目录与 sheets 目录**平级但独立**，交付物只从 sheets 取。
- 条目里的 `answer` 字段是**唯一真源**；卷面答案字母只写进当日 key（选项随机化时换算）。
- 密钥缺失时**拒绝结算，绝不猜测**（对齐 PLAYBOOK §5 铁律 3）。

## 各项目落地形态（差异只在路径）

| 项目 | key 路径 | 说明 |
|---|---|---|
| bb-prep | `03-题库/.keys/<date>.txt` | 按日期；加练卷 `<date>-加练.txt` |
| vocab-app | `.keys/<账户>/<date>.txt` | 多账户隔离（每账户独立进度） |
| AI-Kongzi | 同 vocab-app 形态 | Core Engine 待实现 |

> 路径不同属**项目布局差异**，不是语义差异 —— 内核只约定"密钥与卷面分离"，
> 不约定具体路径（路径由项目注入）。

## 理由

- **交付物纯净**：卷面可整体复制/打印，不担心夹带答案。
- **防泄题**：bb-prep cron 明确禁止向用户展示 `.keys` 内容。
- **可审计**：密钥缺失 → 显式拒绝，而非静默猜答案（"绝不猜测"是三条铁律之一）。

## 影响

- 正向：三项目共用同一隔离语义；交付物与项目库解耦（"独立交付"要求的上游约束）。
- 负向：出卷流程多一次 key 写入；选项随机化时答案需换算。
- 受影响：bb-prep `src/practice.py`（写 key）、`src/settle.py`（读 key 判分）。

## 备选方案（被否决的）

- **方案 A：答案内联在条目正文、卷面复制时剥离** —— 否决：剥离逻辑一旦漏一处即泄题，
  且无法防"用户直接看条目文件"。
- **方案 B：答案加密存条目内** —— 否决：增加复杂度，且违背"零外部依赖"；
  真正的问题是**物理分离**，不是加密强度。
