- ✅ **三层资产 + 版本闸门**：实测 `bb-prep/.gitmodules` → `url = ecs:/srv/git/LESSON-OS.git`、钉 `620a334`，4 仓库 `origin` 全部可达，`LESSON-OS` main = `b145b21`。方向与载体成立（R2：无过度设计）。

- ✅ **judge / pick 走 adapter 的"方向"**：差异真实存在（vocab `judge(raw,word)` vs bb `settle.grade`；`pick_words` vs `pick_items`），抽象层选择正确（**但接口内容有缺口**，见 B1/B2）。
- ✅ **FSRS 暂不入核 + 留可插拔接口**：与「判分纯代码、不误伤」铁律及冷启动条件自洽。
- ✅ **零外部依赖**：6 个模块 import 仅 `datetime / re / random / dataclasses / typing`，全部 stdlib；`grader`/`picker` 的 adapter 占位是接口设计（基类 `raise`），非债务。
- ✅ **golden-set 放内核内 + 纯 `unittest`**（ADR-0002）：与 `AGENTS.md` 铁律 3 一致，未引 pytest。
- ✅ **标准库注册按事实记**：实测 `lib-index/REGISTRY.md:25-43` 记 `LESSON-OS … planned`，明写「门槛①按**事实**记，不按**计划**记——这是注册表可信度的前提」。PLAYBOOK §11 与注册表一致。
- ✅ **AI-Kongzi 绿地判断**：实测 `LearningOS Code/README.md:4` = 「Sprint 2B — Core Engine 待实现」。
- ✅ **占位清单与工单一致**：3 处 `NotImplementedError`（`grader.py:15`、`picker.py:19`、`vault.py:42`）与 MVP-Backlog「技术债清单」4 条完全对应；无消费方 import（两项目 `src/` 搜 `learn_engine` = 0 命中）。
